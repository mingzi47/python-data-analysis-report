  ★ Insight ─────────────────────────────────────
  设计决策

  两种调用模式共存 — 无参数时进入彩色菜单（交互式），带参数时直接执行（适合
  CI/脚本）。bash case
  语句做路由，函数封装做隔离，每个模式一个独立函数，修改某个模式不影响其他。

  Python 路径隔离 — 脚本通过 .venv/bin/python 显式指定解释器，不依赖 shell 的
  python 别名。set -euo pipefail 确保任何命令失败立即终止，避免半成品输出。

  run.sh 的 quick 和 eda/ml 模式 — 不调用 main.py，而是通过 python -c
  内联执行，这样能精确控制哪些阶段运行。quick 模式 50K 样本量约 30
  秒完成，适合快速验证改动是否破坏流水线。
  ─────────────────────────────────────────────────

  创建的文件

  ┌─────────────────┬──────────────────────────────────────────┐
  │      文件       │                   用途                   │
  ├─────────────────┼──────────────────────────────────────────┤
  │ scripts/run.sh  │ 运行管理：完整/快速/EDA/建模/清理        │
  ├─────────────────┼──────────────────────────────────────────┤
  │ scripts/test.sh │ 测试管理：全部/模块/失败重跑/快速/单函数 │
  └─────────────────┴──────────────────────────────────────────┘
