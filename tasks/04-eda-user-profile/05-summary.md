# 05 — 用户行为画像总结

## 描述
汇总问题 2 的四项分析（活跃度分布、推荐偏好、极端用户、购买-评论关系），形成结构化的用户画像总结。

## 依赖
- `01-activity-distribution` 到 `04-purchase-review-relation` 全部完成

## 输入
- 以上四个任务的统计结果和图表

## 输出
- 结构化总结文本 + 数据清洗决策记录

## 步骤
1. 汇总关键数据：用户总数、活跃度分层占比、整体推荐率、极端用户占比
2. 三段式总结：用户规模与活跃度 → 评价行为特征 → 清洗策略与建模建议
3. 明确记录清洗决策：是否剔除极端用户、剔除标准是什么

## 验收标准
- 关键数据点完整
- 清洗决策有数据支撑
- 篇幅控制在半页以内
