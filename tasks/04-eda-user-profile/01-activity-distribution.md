# 01 — 用户活跃度分布分析

## 描述
分析用户评论数和购买数的分布形态。判断大部分用户是"沉默用户"还是"重度用户"。

## 依赖
- 数据清洗完成

## 输入
- `users_df`（含 `products`, `reviews` 列）

## 输出
- 直方图（`outputs/figures/user_activity_distribution.png`）+ 分位数统计

## 步骤
1. `df[['products', 'reviews']].describe(percentiles=[.25, .5, .75, .9, .95, .99])`
2. 画 log-log 直方图：`products` 和 `reviews` 各一张
3. 定义活跃度分层：低（0-25%分位）、中（25-75%）、高（75-95%）、极高（95%+）
4. 统计各层用户数量和占比
5. 计算 Gini 系数（衡量用户活跃度不均）

## 验收标准
- 分位数统计完整
- 活跃度分层标准明确
- 分布形态有描述（预期：极长尾，多数用户评论/购买数很少）
