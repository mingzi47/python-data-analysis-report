# 03 — 极端用户识别

## 描述
识别只发表好评（推荐率 100%）或只发差评（推荐率 0%）的极端用户，评估是否需要在建模中剔除。

## 依赖
- `02-recommend-preference`：需要按用户计算的推荐率

## 输入
- `recommendations_df`（按 user_id 聚合的推荐率）

## 输出
- 极端用户统计报告

## 步骤
1. 统计推荐率 == 1.0（纯好评用户）和推荐率 == 0.0（纯差评用户）的数量和占比
2. 统计这些极端用户的平均评论数（他们是否只评价了极少游戏？）
3. 按评论数分层（1条、2-5条、6-10条、10+条）统计每层的极端用户占比
4. 决定清洗策略：是否剔除仅发表 1-2 条评论的极端用户

## 验收标准
- 极端用户数量和占比明确
- 清洗策略有数据支撑的决策依据
- 决策记录在代码注释中
