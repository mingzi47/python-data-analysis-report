# 02 — 评分分布分析

## 描述
分析游戏评分（推荐率）的分布形态：是两极分化还是集中于高分区？是否存在"高分偏差"？

## 依赖
- 数据清洗完成

## 输入
- `games_df`（已清洗，含 `rating` 列）

## 输出
- 统计摘要 + 直方图（`outputs/figures/rating_distribution.png`）

## 步骤
1. `df['rating'].describe()` 基础统计
2. 计算偏度（skewness）和峰度（kurtosis）
3. 分区间统计：`[0, 0.2)`, `[0.2, 0.4)`, ..., `[0.8, 1.0]` 各区间的游戏数
4. 画直方图 + KDE 叠加，标注均值线和中位数线
5. 计算"高分偏差"指标：评分 > 0.8 的游戏占比

## 验收标准
- 评分分布形态清晰（预期：左偏，大多集中在高分区）
- 偏度和峰度数值有业务解读
