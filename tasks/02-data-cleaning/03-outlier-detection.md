# 03 — 异常值检测

## 描述
检测价格、评分、用户活跃度中的异常值，标记但不一定删除。

## 依赖
- `02-type-conversion`：需要正确的数据类型

## 输入
- `games_df`, `users_df`, `recommendations_df`

## 输出
- 异常值报告（打印输出），可选：标记列 `is_price_outlier` 等

## 步骤
1. **价格异常：** 用 IQR 方法计算 `price_final` 的上下界，打印超过上界的游戏数量和 Top 10
2. **评分异常：** 检查 `rating` 是否在 [0, 1] 范围内，打印超范围记录
3. **用户逻辑异常：** 筛选 `reviews > products` 的用户，打印数量和占比
4. **游玩时长异常：** 检查 `hours` < 0 或极端大值（> 50000 小时），打印数量
5. 所有异常检测结果汇总为一个报告

## 验收标准
- 每种异常类型的数量和典型样本均已输出
- 异常用户（reviews > products）数量可控（< 5%） 或已标记
