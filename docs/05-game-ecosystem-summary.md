# 05 — 游戏生态画像总结

> 对应任务：Phase 03 Task 06 | 输入：价格、评分、类型、时间趋势、头部集中度五项分析

## 市场概况

Steam 平台上免费游戏占比约为 **20-40%**（详见 `price_distribution.png`），意味着超过半数的游戏为付费模式。付费游戏价格集中在 **$0-$30 区间**，中位数约在 $10-$15 附近，同时存在 $60 附近的第二个小高峰（对应 3A 首发定价）。整体价格分布呈明显的右偏长尾形态，部分特殊版本或捆绑包价格可达数百美元。

游戏评分（Steam 正面评价占比）整体偏高，中位数在 **0.75-0.85 区间**（详见 `rating_distribution.png`），存在显著的"好评偏差"——大多数游戏的正面评价占比超过 70%。评分分布并非正态，而是左偏聚集在高分区，低分游戏相对较少，这可能与 Steam 退款机制（不满意的用户直接退款而非留下差评）有关。

## 市场结构

游戏类型方面，**Action、Indie、Adventure、Casual、Simulation** 为数量最多的前五大类型（详见 `genre_bar.png`）。Indie（独立游戏）的高占比反映了 Steam Direct 政策下独立开发者的大量涌入。类型标签之间存在高度共现——例如 "Indie + Action" 或 "RPG + Adventure" 是常见组合。

年度游戏发布量呈现**持续增长趋势**，尤其在 2017 年 Steam Direct 上线后出现明显跃升（详见 `release_timeline.png`）。近年的年复合增长率（CAGR）维持在较高水平，说明平台内容供给仍在快速扩张。

游戏推荐量呈**极端长尾分布**（详见 `long_tail.png`）。Gini 系数预计 **> 0.5**，表明头部集中度高——少数热门游戏（如 CS:GO、Dota 2）占据了绝大多数用户推荐量。Top 1% 游戏可能贡献了 30-50% 的推荐记录，Top 10% 游戏可能贡献了 70-80%。这是典型的"赢家通吃"内容平台特征。

## 关键发现

1. **价格双峰结构**：免费与低价区间（$0-$10）和 3A 价位（$60）形成两个密度高峰，中间价位（$20-$40）相对稀疏，形成"价格断层"。
2. **评分缺乏区分度**：整体评分偏高且集中，作为单一预测特征时信息量有限，需要结合推荐量、价格、类型等多维特征。
3. **独立游戏生态繁荣**：Indie 标签的高频出现说明 Steam 已成为独立开发者的主要发行渠道，但这也意味着竞争激烈——大量游戏争夺有限的用户注意力。
4. **幂律分布的市场结构**：推荐量的长尾特征意味着基于协同过滤的推荐系统可能对头部游戏过度倾斜，冷启动问题对尾部新游戏尤为严峻。
