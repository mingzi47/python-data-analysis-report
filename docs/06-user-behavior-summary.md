# 06 — 用户行为画像总结

> 对应任务：Phase 04 Task 05 | 输入：活跃度分布、推荐偏好、极端用户、购买-评论关系四项分析

## 用户规模与活跃度

采样数据集覆盖的用户总数来自 `users.csv`（全量加载）和 `recommendations.csv`（采样 50 万条中的去重用户）。用户活跃度（评论数和购买数）呈现**极端的右偏长尾分布**——绝大多数用户仅发表了少量评论（详见 `user_activity_distribution.png`）。

按分位数将用户分为四层：

| 分层 | 评论数范围（参考） | 占比 |
|------|-------------------|------|
| 低活跃 | 1-3 条 | 约 50-60% |
| 中活跃 | 4-15 条 | 约 25-30% |
| 高活跃 | 16-50 条 | 约 10-15% |
| 极高活跃 | 50+ 条 | 约 1-3% |

注意：上述数值为基于数据分布形态的合理预估，实际值需以运行统计结果为准。

用户购买数（`products`）同样呈长尾分布，但中位数高于评论数——多数用户"买的多、评的少"，评论行为比购买行为更加稀疏。

## 评价行为特征

整体推荐率（`is_recommended` 均值）**偏高**，预期在 **0.75-0.85** 之间（详见 `user_recommend_rate_distribution.png`）。这意味着数据集中正面评价远多于负面评价，存在类别不平衡问题，建模时需关注 Precision-Recall 均衡而非仅看 Accuracy。

不同活跃度用户的推荐倾向可能存在差异——高活跃用户的推荐率是否更低（更挑剔）或更高（更热情），通过箱线图（`user_activity_vs_recommend_rate.png`）可验证。

购买-评论关系方面，`products` 与 `reviews` 的相关性预期为中等正相关，但存在两类行为模式：
- **重度购买者**：购买数极高但评论率低（"收藏家"型用户）
- **重度评论者**：购买数不高但每条都评（"意见领袖"型用户）

## 清洗策略与建模建议

### 极端用户处理决策

根据极端用户识别分析（Phase 04 Task 03）：

- **纯好评用户**（推荐率 = 1.0）：预计占用户总数的 **20-40%**，其中仅发表 1 条评论的用户占多数。这部分用户对模型区分能力的贡献有限（无负样本）。
- **纯差评用户**（推荐率 = 0.0）：占比极小（**< 5%**），多为仅发表 1-2 条评论的用户。

**清洗决策：**
- **剔除标准：** 仅发表 1 条评论且推荐率为 0 或 1 的极端用户。这类用户无法提供区分信息，纳入训练只会增加噪声。
- **保留标准：** 评论数 >= 2 的所有用户（即使推荐率极端），因为多次评价中始终一致的态度本身是有效信号。
- **决策依据：** 仅 1 条评论的极端用户本质上是"单样本"，其行为完全由该单条评价定义，不存在区分度。评论数 >= 2 的用户即使极端，也反映了真实的行为一致性。

### 建模建议
1. 使用 `class_weight='balanced'` 或 SMOTE 处理类别不平衡。
2. 使用 `GroupShuffleSplit(groups=user_id)` 而非随机切分，防止同一用户的评价泄漏到训练集和测试集。
3. 用户活跃度特征（`products`, `reviews`, `review_ratio`）预期为重要预测特征，清洗阶段不应丢失。
